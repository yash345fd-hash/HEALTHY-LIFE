## 🌟 Overview

**HEALTHY LIFE** is designed specifically for students, young professionals, and gym beginners who want to get fit without breaking the bank. By balancing **Fitness Goals + Precision Nutrition + Daily Food Budget**, the platform eliminates guesswork and provides actionable meal and workout plans tailored to Indian diets and affordable grocery sources.

---

## 🚀 Key Features

- 🎯 **Interactive Plan Generator**: Generate custom diet and workout splits based on height, weight, activity level, dietary preference (Veg / Non-Veg / Vegan / Eggetarian), and daily budget (₹50 to ₹500+).
- 🥗 **Smart Nutrition Breakdown**: Calculate daily calories, protein, carbs, and fats tailored to weight loss, muscle gain, recomp, or maintenance.
- 💰 **Budget Optimizer**: Dynamic grocery lists and affordable protein sources (eggs, soya chunks, paneer, sprouts, whey, chicken).
- 🏋️‍♂️ **Beginner & Intermediate Workout Routines**: Push-Pull-Legs (PPL), Upper-Lower, and Full Body splits with exercise demos, rep ranges, and progression tips.
- 📊 **Interactive Progress Tracking**: Track weight logs, calorie targets, and fitness milestones.
- 🌓 **Modern Dark / Light Mode**: Sleek glassmorphism UI with responsive design across desktop, tablet, and mobile devices.
- ⚡ **Zero Dependencies**: Pure HTML5, Vanilla CSS3, and modern JavaScript for blazing-fast load speeds and high reliability.

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/yash345fd-hash/healthy-life.git
cd healthy-life
```

### 2. Run locally
You can open `index.html` directly in your browser, or serve it with any static server:

```bash
# Using VS Code Live Server extension or Python:
python -m http.server 3000

# Using Node.js npx:
npx serve .
```

Then visit `http://localhost:3000` in your web browser.
